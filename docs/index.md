# Get Started with HA-VLN 2.0

These pages document the released
[HA-VLN 2.0 project](https://github.com/UWMILab/HA-VLN): its Habitat 0.1.7
environment, public HA-R2R and HAPS 2.0 data, and simulator interfaces.

1. [Prepare the dependencies](setup/dependencies.md) and
   [install the runtime](setup/installation.md).
2. [Obtain the public data](data.md), including separately licensed
   Matterport3D scenes.
3. Consult the [simulator API reference](api/human_state.md) when integrating
   a method or investigating simulator behavior.

This is project-level documentation, not a challenge rules or submission guide.
