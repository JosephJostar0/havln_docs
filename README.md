# HA-VLN 2.0 Get Started documentation

This repository contains project-level Get Started documentation for the
[released HA-VLN 2.0 codebase](https://github.com/UWMILab/HA-VLN). It covers
installation, public data, and simulator APIs. Challenge submissions, scoring,
rankings, and phase rules belong to the separate
[RoboWorld 2026 Track 2 challenge site](https://jostarxiong.github.io/havln-challenge-2026/).

This is a local draft based on the earlier documentation backup. The official
HA-VLN webpage has not been changed. Before publication, verify that the
challenge-site URL is live and update the official webpage's Get Started link
in a separate pull request.

Build locally with `mkdocs build --strict`.
